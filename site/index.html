foreman.workflow.yamlYAML 
# A complete, minimal workflow
version: 1
name: Writing assistant
admission:
  when: Substantial writing projects.
  bypass: Unrelated requests.
  entries: [draft]
capabilities:
  draft:
    purpose: Produce the requested document.
    instructions: Write DRAFT.md for the user.
    completion: The document addresses the scope.
    gate: { files: [DRAFT.md] }
    next:
      ready: [deliver]
      incomplete: [draft]
      blocked: [draft]
  deliver:
    purpose: Deliver the document.
    instructions: Summarize and link DRAFT.md.
    completion: The user has the result.
    dependsOn: [draft]
    terminal: true

A few things to know.

Is Foreman another coding agent?

Foreman is a plugin for OpenCode. Your agent still uses its normal tools to do the work. Foreman adds configurable workflows, persistent progress, routing, and completion gates.

How does it work with Jev?

Jev chooses between eligible workflow transitions. Foreman determines which transitions are allowed, checks configured gates, saves state, and continues the workflow. Learn about JevRouter ↗

Do I need it for every request?

No. The default workflow admits substantial engineering work and lets small requests bypass it. You can also explicitly enter with foreman: or bypass with foreman bypass:.

Does passing a gate guarantee good code?

No. Gates check configured evidence and outputs. Code quality still depends on the model, the instructions, and the checks you ask it to run. Foreman makes the process explicit and inspectable.
